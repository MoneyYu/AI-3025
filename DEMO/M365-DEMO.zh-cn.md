以下是所有在 Microsoft 365 Copilot 教学 DEMO 中使用的提示

### DEMO 1 - Word 中探索文件
```
将此文件摘要为5个要点，并建议后续步骤。
```

### DEMO 2 - Word 中进一步提问
```
如何在纽约建立新企业？请用编号列表回答。
```

### DEMO 3 - 建立商业名称
```
能否为我的清洁公司建议一个名称？
```

### DEMO 4 - 撰写商业计划
```
基于/Business Idea.docx中的信息，为「[选择的公司名称]」撰写一份商业计划。包括执行摘要、市场概况和财务预测。
```

### DEMO 5 - 建立利润表格
```
建立此文件中预测利润的表格。
```

或者替代提示：
```
建立未来5年的预测利润表格，从今年开始。今年的利润应为$10,000，每年增长12%。
```

### DEMO 6 - Excel 中视觉化财务数据
```
建议视觉化这些财务预测的方法。
```

### DEMO 7 - PowerPoint 建立演示文稿
```
建立一个关于位于纽约市的企业清洁服务「[公司名称]」的演示文稿。演示文稿应包括使用专业清洁公司的好处。
```

### DEMO 8 - 添加新幻灯片
```
添加一张关于环保清洁方法优势的幻灯片。
```

### DEMO 9 - Outlook 查看日历
```
本周我有哪些已排定的活动？
```

### DEMO 10 - 撰写融资邮件
```
撰写一封给银行经理的电子邮件，请求安排会议讨论商业清洁公司的融资事宜。邮件应简洁且语调专业。
```
