Here are all the prompts used in Microsoft Edge Copilot tutorial DEMO:

### DEMO 1 - Exploring Documents in Edge
```
Summarize this document into 5 key points, and suggest next steps.
```

### DEMO 2 - Learning How to Establish a Business
```
How do I begin establishing a business in New York?
```

### DEMO 3 - Creating a Business Name
```
Suggest a name for my cleaning business.
```

### DEMO 4 - Writing a Business Plan
```
Based on the content of this document, create a business plan for my cleaning business.
```

### DEMO 5 - Designing Company Logo
```
Create a business logo for a cleaning company. The logo should be circular and include a landmark building from New York.
```

### DEMO 6 - Creating Financial Projections
```
Create a projected profit table for the next 5 years, starting from this year. This year's profit should be $10,000, with a 12% increase each year.
```

### DEMO 7 - Chart Visualization Suggestions
```
What are some good methods to visualize these projections with charts?
```

### DEMO 8 - Excel Chart Creation Guidelines
```
How do I create a line chart in Excel?
```

### DEMO 9 - Creating Presentation Content
```
Write a summary of the benefits of a commercial cleaning company for businesses. The summary should include five short bullet points.
```

### DEMO 10 - Generating Office Images
```
Create a photorealistic image of a clean office.
```

### DEMO 11 - Image Analysis
```
What does this image show?
```

### DEMO 12 - Image Suitability Assessment
```
Is this image helpful for promoting a commercial cleaning business?
```

### DEMO 13 - Writing Image Caption
```
Write a short text to accompany this image, emphasizing the professionalism of our cleaning staff.
```

### DEMO 14 - Slide Title Suggestions
```
Suggest a good title for a slide containing this image and text.
```

### DEMO 15 - Writing Financing Email
```
Write an email to a bank manager requesting a meeting to discuss financing for a commercial cleaning company. The email should be concise and professional in tone.
```
