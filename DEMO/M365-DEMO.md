Here are all the prompts used in the Microsoft 365 Copilot teaching DEMO

### DEMO 1 - Exploring documents in Word
```
Summarize this document into 5 key points, and suggest next steps.
```

### DEMO 2 - Further inquiries in Word
```
How do I setup a new business in New York? Answer with a numbered list.
```

### DEMO 3 - Creating a business name
```
Can you suggest a name for my cleaning business?
```

### DEMO 4 - Writing a business plan
```
Write a business plan for "[chosen company name]" based on the information in /Business Idea.docx. Include an executive summary, market overview, and financial projections.
```

### DEMO 5 - Creating a profit table
```
Create a table of the projected profits in this document.
```

Or alternative prompt:
```
Create a table of projected profits for the next 5 years, starting with this year. The profit this year should be $10,000 and it should increase by 12% each year.
```

### DEMO 6 - Visualizing financial data in Excel
```
Suggest ways to visualize these financial projections.
```

### DEMO 7 - Creating a presentation in PowerPoint
```
Create a presentation about a corporate cleaning service named "[company name]" in New York City. The presentation should include the benefits of using a professional cleaning business.
```

### DEMO 8 - Adding a new slide
```
Add a slide about the benefits of an eco-friendly approach to cleaning.
```

### DEMO 9 - Viewing calendar in Outlook
```
What events do I have scheduled this week?
```

### DEMO 10 - Writing a funding email
```
Write an email to a bank manager requesting a meeting to discuss funding for a commercial cleaning business. The email should be concise and the tone should be professional.
```
