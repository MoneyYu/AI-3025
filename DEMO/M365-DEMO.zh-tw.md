以下是所有在 Microsoft 365 Copilot 教學 DEMO 中使用的提示：

### DEMO 1 - Word 中探索文件
```
將此文件摘要為5個要點，並建議後續步驟。
```

### DEMO 2 - Word 中進一步提問
```
如何在紐約建立新企業？請用編號列表回答。
```

### DEMO 3 - 建立商業名稱
```
能否為我的清潔公司建議一個名稱？
```

### DEMO 4 - 撰寫商業計畫
```
基於/Business Idea.docx中的資訊，為「[選擇的公司名稱]」撰寫一份商業計畫。包括執行摘要、市場概況和財務預測。
```

### DEMO 5 - 建立利潤表格
```
建立此文件中預測利潤的表格。
```

或者替代提示：
```
建立未來5年的預測利潤表格，從今年開始。今年的利潤應為$10,000，每年增長12%。
```

### DEMO 6 - Excel 中視覺化財務資料
```
建議視覺化這些財務預測的方法。
```

### DEMO 7 - PowerPoint 建立簡報
```
建立一個關於位於紐約市的企業清潔服務「[公司名稱]」的簡報。簡報應包括使用專業清潔公司的好處。
```

### DEMO 8 - 添加新投影片
```
添加一張關於環保清潔方法優勢的投影片。
```

### DEMO 9 - Outlook 查看行事曆
```
本週我有哪些已排定的活動？
```

### DEMO 10 - 撰寫融資郵件
```
撰寫一封給銀行經理的電子郵件，請求安排會議討論商業清潔公司的融資事宜。郵件應簡潔且語調專業。
```
